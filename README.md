# Gmail Email Manager

A Python-based Gmail Inbox Manager that scans, categorizes, analyzes, and helps clean up your Gmail inbox.

## Features

- Secure Gmail Login using App Password

- Scan Inbox Emails

- Categorize Emails Automatically

- Generate CSV Reports

- View Top Email Senders

- Bulk Delete Emails by Category

- Fully Local Processing

- No AI Required

- No External Services

---

## Email Categories

The tool automatically classifies emails into:

- Salary
- Banking
- Credit Card
- Investment
- Jobs
- LinkedIn
- GitHub
- Learning
- Shopping
- Travel
- Newsletter
- Promotion
- Social
- Others
